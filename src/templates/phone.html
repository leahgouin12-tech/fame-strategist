If the phone reaches nothing

Windows blocks incoming connections by default, and a phone hotspot counts as a public network. Allow this port once, in a PowerShell that says Run as administrator:

netsh advfirewall firewall add rule name="Fame Strategist" dir=in action=allow protocol=TCP localport={{ port }} profile=any

The laptop has to stay awake and on the same network as the phone. Let it sleep and the icon opens a page that cannot load — that is the trade for the files never leaving this machine.

What this is not. It is not an app you can use on a plane, and not one that works with the laptop closed: the picture work happens here, so this is a remote control with an icon. The PIN is a door on your own network, not a login system — five wrong guesses bring {{ cooldown }} minutes of waiting, and only you can change the PIN, from this page, on this laptop.
